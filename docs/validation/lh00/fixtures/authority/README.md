für Produktläufe. Alle zwei fachlichen Quellen und vier direkt hashgebundenen
Governance-Dateien sind enthalten. Weitere Referenzen in unverändert kopierter

behauptet keine vollständige Installation oder Sammlung. Beide Receipt-Validatoren
können mit --repo bzw. -Repo auf dieses Verzeichnis gerichtet werden. Keine
Folgeprompts ohne neuen Testauftrag ausführen.
